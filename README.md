# ⚙️ Gear Ratio & Speed Analysis using MATLAB  

## 📌 Project Overview  
This project develops an interactive MATLAB-based tool to analyze gear systems by calculating gear ratios and output speeds based on user-defined inputs. The objective is to understand how speed is transmitted across gears and visualize the relationship between input and output speeds.

The model also generates graphical output to help interpret gear behavior in mechanical systems such as gearboxes and transmissions.

---

## ⚙️ System Concept  

The relationship between input and output speed is given by:

ω₂ = ω₁ × (N₁ / N₂)

Where:  
- N₁ = Number of teeth on driver gear  
- N₂ = Number of teeth on driven gear  
- ω₁ = Input speed (RPM)  
- ω₂ = Output speed (RPM)  

---

## ⚙️ Features  
- Interactive user input for gear parameters  
- Automatic calculation of gear ratio and output speed  
- Graphical visualization of speed relationship  
- Simple and efficient MATLAB implementation
